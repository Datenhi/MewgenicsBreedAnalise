**Mewgenics Breed Analyzer** — неофициальный инструмент для сообщества игры *Mewgenics*.
Загрузите своё сохранение `steamcampaign*.sav` — и приложение покажет всех котов, когда-либо
живших в вашем доме: кто сейчас жив, кто ушёл в поход, кто на пенсии, а кто уже на кладбище.
Для любого кота можно построить дерево всех его потомков и всех его предков с коэффициентами
инбридинга на каждой ветке.

## ✨ Возможности

- **📂 Загрузка сохранения** — drag & drop или выбор файла; поддерживаются `steamcampaign*.sav` из папки сохранений Mewgenics.
- **🔒 100% локальный разбор** — файл обрабатывается прямо в браузере средствами WebAssembly (sql.js); он **никуда не отправляется**, не сохраняется и не логируется. Бэкенд и телеметрия отсутствуют.
- **👥 Полный список котов** — имя, номер, пол (самец / самка / ?), класс, коэффициент инбридинга.
- **💀 Определение статуса каждого кота**:
  | Статус | Значение |
  |---|---|
  | 🟢 В доме | сейчас живёт в доме (с указанием комнаты) |
  | 🔵 В походе | ушёл в приключение |
  | ⚫ Мёртв | Organ Grinder забрал его |
  | ⚪ Не в доме | жив, но продан / отдан / на пенсии / пожертвован |
  | ◻️ Нет данных | встречается только в родословной |
- **🎛 Фильтры списка** — «Живые» (включены **по умолчанию**), «В доме», «Мёртвые», «Все» + мгновенный поиск по имени или номеру кота.
- **🌳 Деревья потомков и предков** — интерактивные: сворачиваемые ветки, переход по клику на любого кота, счётчики прямых детей, всех потомков и предков; мёртвые коты помечены черепом.
- **🧬 Инбридинг** — коэффициент у каждого кота, красная подсветка сильного инбридинга (≥ 25%).
- **📊 Сводная статистика** — всего котов в родословной, живых сейчас, из них в доме, мёртвых.
- **🎯 Умный автовыбор** — после загрузки открывается живой кот с самым большим потомством.
- **⚠️ Честные предупреждения** — если часть данных прочитана неуверенно, парсер сообщит об этом, а не промолчит.

## 🔒 Приватность

> Файл сохранения — это ваши личные игровые данные. Приложение спроектировано так,
> чтобы они никогда не покидали ваш компьютер:
>
> - парсинг выполняется **в браузере** через SQLite, скомпилированный в WebAssembly;
> - **нет сервера, нет сетевых запросов** с содержимым файла, нет аналитики;

## 🧠 Как это работает

Формат сохранения Mewgenics официально не документирован и восстановлен методом
reverse engineering (файл `.sav` открывается в любом SQLite-просмотрщике):

1. **`.sav` — это база данных SQLite 3** (проверяется по заголовку `SQLite format 3`).
2. **Таблица `cats`** — `key INTEGER` (номер кота) и `data BLOB`: блоб кота, сжатый **LZ4**
   (два варианта обёртки, распаковка — собственная реализация на TypeScript без зависимостей).
   Внутри распакованного блоба: id, длина имени, имя в UTF-16LE, пол (0 — самец, 1 — самка,
   2 — ?) и **флаги статуса**: `0x0020` — мёртв, `0x0002` — на пенсии, `0x4000` — пожертвован.
3. **Таблица `files`**, запись `pedigree` — граф родословной: поток int64-слотов с секциями;
   каждая запись — четвёрка *(ребёнок, родитель1 | -1, родитель2 | -1, коэффициент инбридинга: double)*.
4. **`files.house_state`** — кто прямо сейчас живёт в доме (ключ кота, комната, координаты);
   **`files.adventure_state`** — кто ушёл в поход.
5. Всё это выполняет **sql.js** (SQLite → WebAssembly) внутри страницы, поэтому ни байт
   сохранения не уходит из браузера.

Ключевой вывод, ради которого всё затевалось: игра хранит в `cats` **всех котов за всю игру**,
включая давно умерших. Флаг `0x0020` в блобе позволяет отделить живых от мёртвых — поэтому
список по умолчанию показывает только текущих питомцев.

## 🗂 Структура проекта

```
src/
  app/
    page.tsx               # весь UI: загрузка файла, список, карточка кота, вкладки деревьев
    layout.tsx             # метаданные и шрифты
  components/
    family-tree.tsx        # деревья потомков/предков, бейджи пола и инбридинга
    ui/                    # компоненты shadcn/ui
  lib/
    mewgenics-parser.ts    # парсер .sav: sql.js + LZ4 + бинарные форматы блобов
public/
  sql-wasm.js / sql-wasm.wasm   # SQLite WASM (загружается <script>-ом, кешируется один раз)
```

## 🩺 Устранение неполадок

- **Порт 3000 занят** → `npx next dev -p 3001`.
- **Windows: `npm run dev` падает** (в скрипте есть `tee`, которого нет в cmd) → запускайте напрямую `npx next dev -p 3000`.
- **«Не удалось загрузить SQL-движок (sql.js)»** → в `public/` нет `sql-wasm.js`/`sql-wasm.wasm`; выполните `npm run wasm:update`.
- **«Это не похоже на сохранение Mewgenics»** → выбран не тот файл; нужен `steamcampaign*.sav` из папки сохранений игры (не `*.sav` других игр и не скриншот/архив).
- **Кот без имени или без статуса** → его блоб не распаковался (парсер честно напишет об этом в предупреждении); такой кот виден в фильтре «Все».

## ⚠️ Ограничения

- Формат сохранения восстановлен эвристически и **не официальен**: после крупного патча игры
  парсер может потребовать обновления.
- Отдельные блобы могут не распаковаться (нестандартная обёртка LZ4) — для таких котов статус
  помечается как неизвестный, в статистике они не учитываются.
- У котов-рекордсменов дерево потомков может быть очень большим — ветки сворачиваются,
  но первичная отрисовка занимает заметное время.
